# Sarah Hammad — Portfolio

Complete site. Upload **the contents of this folder** to your repository root, keeping the folder structure exactly as-is.

```
index.html
support.js
image-slot.js
ContactBand.dc.html
.nojekyll
assets/          (project images, icons, tokens)
components/      (fig-tokens.css, fig-typography.css)
uploads/         (source screens, CV, PDFs)
```

## Publish with GitHub Pages

1. Upload every file and folder above to the repo root.
2. Settings → Pages → Source: **Deploy from a branch** → Branch: **main**, folder **/ (root)** → Save.
3. Wait about a minute, open the published URL, then hard-refresh (Cmd/Ctrl + Shift + R) to bypass cache.

`.nojekyll` is required — without it GitHub Pages ignores some files and images will 404.

## Updating

Re-upload the changed files and commit. Hard-refresh after every deploy.
