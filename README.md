# Sarah Hammad — Portfolio

Single-file portfolio site. All images, styles, and scripts are inlined into `index.html`, so no other files are needed.

## Publish with GitHub Pages

1. Upload `index.html` (and `.nojekyll`) to the repository root.
2. Settings → Pages → Source: **Deploy from a branch** → Branch: **main**, folder **/ (root)** → Save.
3. Wait about a minute, open the published URL, then hard-refresh (Cmd/Ctrl + Shift + R).

## Updating

Replace `index.html` with a new export and commit. Nothing else to change.
